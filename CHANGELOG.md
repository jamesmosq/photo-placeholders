# Photo Placeholders Changelog

## [Unreleased]

### Added

- Generator dialog to insert placeholder photos from picsum.photos: random, by image id or by seed.
- Square images, grayscale and blur (1–10) filters, `.jpg` / `.webp` extensions.
- Automatic `?random=N` so each inserted image is different, including multi-caret inserts.
- Output as URL, HTML `<img>`, CSS background, Markdown, JSX or `src` attribute.
- Live preview and a paginated gallery with thumbnails and authors.
- Quick insert with the last used settings.
- Live templates: `picsum`, `picsumimg`, `picsumbg`, `picsummd`.
- English UI with Spanish translation.
